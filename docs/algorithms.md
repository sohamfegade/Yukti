# Algorithms

This document outlines the algorithms that will be implemented in Phase 2 of Yukti.

## Search Intelligence
- **Breadth-First Search (BFS)**: Explores nodes layer by layer. Guarantees shortest path in unweighted graphs.
- **Depth-First Search (DFS)**: Explores as far as possible along each branch before backtracking.
- **A* Search**: Uses a heuristic to guide the search towards the goal efficiently.

## Game Intelligence
- **Minimax**: Minimizes the possible loss for a worst-case scenario.
- **Alpha-Beta Pruning**: Optimization of Minimax that prunes branches that cannot possibly influence the final decision.

## Probabilistic Intelligence
- **Bayesian Inference**: Updating probabilities based on evidence in a Bayesian Network.
- **Value Iteration**: Dynamic programming algorithm for solving Markov Decision Processes (MDPs).
